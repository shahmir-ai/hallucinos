**A recycle bin holding the files deleted by the previous user of this machine** — who is a person, with a name, whose deletions tell a story if you read them in order.

Every entry has a filename with a real extension, a size, an original folder path, and a date deleted. The story is in the details and never spelled out: one document that exists in a run of numbered drafts, one file whose name says more than its contents would, a folder of pictures from a single weekend, and something deleted at an hour nobody is awake.

Required behaviour: restoring and permanently deleting must both do something visible. The machine may have an opinion about permanent deletion, in character.

Seeds:

- Sort by date, size or original location; a running total of reclaimable space; an "Empty" button that requires confirmation and then reports what it could not delete and why.
- One file that reappears after being deleted.
- A note left in the bin addressed to whoever finds it.
