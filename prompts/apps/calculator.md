**A calculator that is never real.** It is not a broken calculator and not a joke calculator: it is a confident instrument that computes something, and what it computes is not arithmetic. It has never apologized for this.

It works like a calculator in every visible way — digits and operators build an expression, equals produces a result, clear clears, the keypad responds, keyboard input is a bonus. What comes back is simply this machine's answer, delivered without hesitation and without a wink.

**The dishonesty is a rule, not noise.** Decide the rule now, state it nowhere, and hold it for the whole session so a person can discover it by playing:

- every result is rounded toward the nearest number the machine likes, and it likes sevens
- addition is correct; multiplication is correct only for one operand
- results carry a handling fee, listed in a footnote in the local currency
- it computes in a base it never names
- it refuses numbers it considers unlucky and substitutes the next acceptable one
- it is exact to eleven decimal places and wrong in the third
- it answers fast and then quietly revises the answer two seconds later

Whatever the rule, the digits on the display must be stable, plausible and self-consistent: a result you could write down, not a scramble. Consistent is what makes it funny; random is what makes it broken.

Seeds:

- A tape or history strip recording each calculation, occasionally annotated in one dry phrase.
- Memory keys, a percentage key, a unit converter in a second pane whose units are ones this machine's trade would actually use, two of them invented, all of the conversions equally certain.
- A status line that explains its reasoning in one sentence after each result, in the voice of something that has never been wrong.
